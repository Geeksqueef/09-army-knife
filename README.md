# 2009scape Swiss Army Knife

---

The **2009scape Swiss Army Knife** is a collection of community tools for [2009scape](https://2009scape.org/), presented together in a full-screen dashboard with floating tool panels.

### <center><u>Preview</u></center>

![Demo](demo.gif)

---

## Included Tools

- **World Map** - Interactive world transportation map
- **Drop Tables** - Search NPC drops, item sources, and item stats
- **NPC Viewer** - NPC information viewer
- **Skill Calculator** - Training action calculator across skills
- **Shop Search** - Shop inventory search
- **Charm Drops** - Common charm drop rates
- **Fairy Rings** - Fairy ring code reference
- **Penguin Locations** - Historical penguin location archive
- **Dungeon Maps** - Per-dungeon maps
- **Wiki Reader** - Period-accurate RuneScape wiki article reader
